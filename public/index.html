Sign In

Sign in if you already have an account, or create one. Username is unique (used to log in).

By default passwords are hashed client-side with SHA-256 before sending to Firestore. This is for demo use only — not production secure. Use Firebase Auth for production.

Quick guide

  1. Create an account if your username doesn't exist.
  2. When signed in you'll be redirected to the dashboard to create or join groups.
  3. Groups are joinable by a 5-character ID. Owners are stored in Firestore.
Firebase config
Paste your Firebase config into the top of index.html, app.html, and chat.html where noted.
